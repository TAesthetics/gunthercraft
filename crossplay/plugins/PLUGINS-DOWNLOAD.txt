========================================
GUNTHERCRAFT - CROSSPLAY SERVER PLUGINS
Plugin download list (all versions for Paper 1.21.x)
========================================

[REQUIRED - CROSSPLAY]
GeyserMC (Spigot build)
  https://geysermc.org/download
  -> Place Geyser-Spigot.jar in /plugins/

Floodgate (Spigot build)
  https://geysermc.org/download
  -> Place floodgate-spigot.jar in /plugins/
  !! Install Floodgate BEFORE Geyser !!

[REQUIRED - CORE FUNCTIONALITY]
EssentialsX
  https://essentialsx.net/downloads.html
  -> EssentialsX.jar + EssentialsXChat.jar + EssentialsXSpawn.jar

LuckPerms
  https://luckperms.net/download
  -> LuckPerms-Bukkit-x.x.x.jar

[REQUIRED - PROTECTION]
WorldGuard
  https://dev.bukkit.org/projects/worldguard/files
  -> worldguard-bukkit-x.x.x.jar

WorldEdit
  https://dev.bukkit.org/projects/worldedit/files
  -> worldedit-bukkit-x.x.x.jar (required by WorldGuard!)

CoreProtect
  https://www.spigotmc.org/resources/coreprotect.8631/

[RECOMMENDED - MAP & WORLD]
BlueMap
  https://www.spigotmc.org/resources/bluemap.83557/
  -> Alternative: Dynmap (https://www.spigotmc.org/resources/dynmap.274/)

Chunky (chunk pre-generation)
  https://www.spigotmc.org/resources/chunky.81811/

ChunkyBorder (world borders with Chunky)
  https://www.spigotmc.org/resources/chunkyborder.80461/

[RECOMMENDED - COMMUNITY]
DiscordSRV
  https://www.spigotmc.org/resources/discordsrv.18494/
  -> Enter your bot token in config.yml!

[PERFORMANCE]
Spark (profiler)
  https://spark.lucko.me/download

ViaVersion (multi-version support)
  https://www.spigotmc.org/resources/viaversion.19254/

ViaBackwards (older clients)
  https://www.spigotmc.org/resources/viabackwards.27448/

========================================
INSTALLATION ORDER:
1. Download Paper: https://papermc.io/downloads
2. Start server once (accept EULA), then stop
3. Place plugins in /plugins/: Floodgate FIRST, then Geyser
4. Start server and check logs for errors
5. Firewall: open port 25565 (TCP/Java) + 19132 (UDP/Bedrock)
