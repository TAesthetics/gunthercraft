⛏ GUNTHERCRAFT

Two Servers. One Community. 50+ Players.

Gunthercraft is a community Minecraft server with two parallel game modes: a Crossplay server where Java and Bedrock players play together with quality-of-life plugins, and a Java Modded server with a full community-built modpack. Bedrock can't run Forge mods, so we run both — everyone gets to play.

🌍

Crossplay Server

Plugin · Paper · GeyserMC
JAVA BEDROCK

Near-vanilla gameplay with plugins. Java and Bedrock players join the same world through GeyserMC + Floodgate. Earth Map, no mod downloads required.

  • Paper / Purpur 1.21.x
  • GeyserMC + Floodgate crossplay
  • Earth Map + BlueMap web map
  • EssentialsX, WorldGuard, LuckPerms
  • 60–80 player slots
