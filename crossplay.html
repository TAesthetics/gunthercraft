The Concept

The Gunthercraft Crossplay server runs on Paper/Purpur with GeyserMC + Floodgate, letting Java AND Bedrock players join the same world. Near-vanilla gameplay with quality-of-life plugins, an Earth Map as the main world, and zero mod downloads required.

💡 Why GeyserMC?
GeyserMC translates the Bedrock protocol to Java in real time. Your server runs Java, but Bedrock players connect normally via the Bedrock launcher. Floodgate handles authentication for Bedrock accounts without Java accounts.
⚠️ No Mods: This server cannot use Forge/NeoForge mods because Paper is a plugin-based fork of Spigot. For the full mod experience, see the Modpack Server plan.

🔌

GeyserMC + Floodgate Setup

The crossplay magic happens through two plugins:

  • GeyserMC — Protocol translator (Bedrock ↔ Java)
  • Floodgate — Auth bridge so Bedrock accounts can join without Java accounts

Bedrock port: 19132 (UDP) — make sure to open this in firewall and provider settings.

Java port: 25565 (TCP) — standard MC port.

Crossplay Launch Checklist

Phase 1 — Infrastructure (Week 1)

  • 1Choose hosting and order server (12GB RAM)
  • 2Install Paper / Purpur 1.21.x
  • 3Open ports: 25565 (TCP, Java) + 19132 (UDP, Bedrock)
  • 4Set up reverse proxy / DDoS protection if needed

Phase 2 — Crossplay & Plugins (Week 1–2)

  • 5Install GeyserMC + Floodgate
  • 6Test Bedrock connection from phone/console
  • 7Generate and import Earth Map (BlueMap recommended)
  • 8Install core plugins (Essentials, LuckPerms, WorldGuard)
  • 9Configure CoreProtect and permissions

Phase 3 — Community & Launch (Week 2–3)

  • 10Set up Discord server with channels and roles
  • 11Configure DiscordSRV chat bridge
  • 12Write rules and Bedrock connection guide
  • 13Brief staff team and set up moderation tools
  • 14Soft launch with friends → Feedback → Full launch
💡 Tip: Launch the Crossplay server first — it's faster to set up and accessible for everyone. The modpack server can come 1–2 weeks later once mod testing is complete.
