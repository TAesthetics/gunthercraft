The Concept

The Gunthercraft Modpack server runs a full community-built modpack on NeoForge. It combines warfare, Create automation, horror, cyberpunk, and RP elements into one cohesive experience. Java only — designed for 50+ players who want the full mod experience.

⚔️

Java Modded Server

JAVA ONLY NEOFORGE

  • Full community modpack with 30+ mods
  • Warfare, Create automation, Horror, Cyberpunk themes
  • Earth Map + Custom Dimensions
  • RP-ready with Simple Voice Chat
  • Distributed via CurseForge / Modrinth
  • FTB Teams & Chunks for protection
⚠️ Java Only: Bedrock players cannot connect to Forge/NeoForge servers. If you want crossplay, see the Crossplay Server plan.
💡 Why a Modpack?
The Discord community requested specific mods — warfare, Create, horror, cyberpunk RP. A unified modpack ensures everyone has the same mods, no version mismatches, and one-click install via launcher.

📎

Modpack Distribution

The modpack must be distributed to all players. Best options:

  • CurseForge App — Upload modpack, players install with one click
  • Modrinth Launcher — Open-source alternative, growing fast
  • MultiMC / Prism Launcher — ZIP export for advanced users
  • Custom Launcher — Branded experience (e.g. Technic, ATLauncher)

Server-side configs: Tweak balancing, performance settings, and disable client-only mods on server to save RAM.

Modpack Launch Checklist

Phase 1 — Mod Selection & Testing (Week 1–2)

  • 1Finalize mod list with community input
  • 2Test mod compatibility in local instance
  • 3Configure mod settings and balance
  • 4Set up server-side performance mods

Phase 2 — Server Setup (Week 2–3)

  • 5Choose hosting and order server (16GB+ RAM)
  • 6Install NeoForge 1.20.1 server
  • 7Upload modpack and configs
  • 8Generate Earth Map / set up Terra mod
  • 9Configure FTB Teams & Chunks for protection

Phase 3 — Distribution & Launch (Week 3–4)

  • 10Upload modpack to CurseForge / Modrinth
  • 11Internal testing with 5–10 players
  • 12Pin modpack download link in Discord
  • 13Write modpack guide & install instructions
  • 14Soft launch → Feedback → Full launch
💡 Tip: Test the modpack thoroughly before launch — mod conflicts can take days to debug. Start small with core mods and add the rest after stability is confirmed.
